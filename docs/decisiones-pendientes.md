# Decisiones pendientes

Este documento registra aspectos que todavía no se encuentran definidos y que deberán resolverse antes o durante las siguientes etapas de desarrollo.

## Contenido educativo

- Definir los temas de ciberseguridad que formarán parte de la plataforma.
- Establecer la cantidad de contenidos, actividades, simulaciones y evaluaciones por tema.
- Elaborar y validar el contenido educativo de cada recurso.

## Datos y tecnología

- Revisar y ajustar el modelo de base de datos según los requerimientos definitivos.
- Seleccionar la base de datos que utilizará la plataforma.
- Definir la estructura interna del proyecto Flask.
- Establecer el mecanismo de creación y administración de cuentas administrativas.

## Accesibilidad

- Elaborar una lista de criterios de accesibilidad basados en WCAG 2.2 Nivel AA.
- Definir el método de evaluación de navegación por teclado, contraste, formularios, textos alternativos y compatibilidad con tecnologías de asistencia.
- Realizar pruebas de accesibilidad durante el desarrollo.

## Seguridad

- Definir las reglas de validación de datos.
- Establecer medidas de control de acceso según roles.
- Implementar protección de contraseñas, formularios y sesiones.
- Definir qué datos personales serán necesarios para el registro de ciudadanos.

## Funcionamiento y despliegue

- Definir las métricas de participación y aprendizaje.
- Determinar dónde se ejecutará o publicará la plataforma.
- Planificar las pruebas funcionales, de accesibilidad y seguridad.
