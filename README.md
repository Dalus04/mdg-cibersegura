# MDG Cibersegura

Plataforma web educativa orientada a fortalecer las competencias de ciberseguridad de la ciudadanía del distrito de Guadalupe.

## Objetivo

Desarrollar una plataforma accesible e interactiva para la Municipalidad Distrital de Guadalupe que permita informar, orientar y evaluar conocimientos sobre riesgos digitales frecuentes, como el phishing, el uso de contraseñas inseguras, la exposición de datos personales y la navegación en sitios no confiables.

## Alcance previsto

La plataforma contará con las siguientes funciones:

- Registro e inicio de sesión de ciudadanos.
- Consulta de contenidos educativos organizados por temas.
- Desarrollo de actividades prácticas.
- Simulaciones de situaciones digitales en un entorno seguro.
- Evaluaciones con retroalimentación y resultados.
- Registro y visualización del progreso de aprendizaje.
- Gestión de contenidos, actividades, simulaciones y evaluaciones mediante un rol administrativo.

## Principios del proyecto

- Accesibilidad orientada a los criterios de WCAG 2.2 Nivel AA.
- Navegación clara, estructura semántica y uso mediante teclado.
- Diseño adaptable a computadoras, tabletas y teléfonos móviles.
- Protección de contraseñas mediante hash.
- Control de acceso según roles y validación de datos ingresados.

## Estado actual

El proyecto se encuentra en etapa inicial de desarrollo. Los temas educativos específicos, el modelo definitivo de base de datos, las decisiones de despliegue y los criterios detallados de accesibilidad se documentarán progresivamente.
